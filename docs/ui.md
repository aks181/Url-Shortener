# UI Components

## Overview

All UI elements in this app use [shadcn/ui](https://ui.shadcn.com/). Do **not** create custom UI primitives — always use shadcn components.

## Rules

- **Always use shadcn/ui components.** Never hand-roll buttons, inputs, dialogs, badges, cards, or any other UI primitive.
- **Do not modify `components/ui/`.** These files are auto-generated by shadcn. Treat them as read-only.
- **Extend via wrappers.** If you need custom behaviour, create a wrapper component in `components/` that composes shadcn primitives.
- **Add new components with the CLI.** To add a shadcn component that is not yet in the project run:
  ```bash
  npx shadcn@latest add <component-name>
  ```
- **Use `cn()` for class merging.** Import from `@/lib/utils` when combining Tailwind classes on shadcn components.

## Available Components

Check `components/ui/` for the list of shadcn components already installed in the project before adding new ones.
